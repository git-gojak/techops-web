Changelog — GoJak TechOps

Catatan perubahan aplikasi GoJak TechOps berdasarkan riwayat commit repository "git-gojak/techops-web".

Format:

- Added — penambahan fitur.
- Changed — perubahan atau penyempurnaan.
- Fixed — perbaikan masalah.

---

22 November 2026

Changed

- Mengubah penyimpanan sesi Admin dari "sessionStorage" menjadi "localStorage".
- Menambahkan sinkronisasi status Admin ketika terjadi perubahan autentikasi antar-tab.
- Menyempurnakan tampilan kartu Kondisi Perangkat pada dashboard.
- Menyesuaikan tata letak dashboard untuk tampilan mobile.
- Menyempurnakan pemformatan tanggal dan waktu.
- Menyempurnakan informasi model dan serial perangkat pada dashboard.

21 November 2026

Changed

- Menyempurnakan struktur HTML aktivitas maintenance.
- Menyempurnakan logika dan tampilan jadwal maintenance.
